SimpleWAS

OpenJDK 1.8 표준 API 만으로 만든 스레드 풀 기반 WAS 입니다.

엔드포인트

  • GET / — 이 정적 페이지
  • GET /hello?name=claude — JSON 인사
  • GET /health — 헬스 체크
  • POST /echo — 요청 본문 그대로 반환
  • POST /login · GET /me — 로컬 파일 세션
  • POST /reports · GET /reports?id= — 인스턴스 로컬 리포트
  • GET /assets · POST /assets?name= — NFS 공유 산출물
  • POST /upload?filename= — S3 업로드 (외부화 완료)
  • GET /instance — IMDS 인스턴스 정보
  • GET /admin/config — 운영 접속 정보
